# Architecture index

MoodOS converts a user's emotional state, preferences, context, and constraints into a coherent personalized experience.

**Blueprint sentence:** MoodOS is an MCP-based AI orchestration system that combines persistent user memory (Mem0), adaptive RAG, live external APIs, semantic retrieval, context-aware ranking, and experience planning to transform a user's emotional and situational state into a personalized real-world experience.
